دفتر DAFTAR - نموذج أولي قابل للنشر على Vercel

محتويات الحزمة:
- index.html: تطبيق تجريبي عربي متجاوب بواجهتي الكاشير والزبون.
- vercel.json: إعدادات توجيه بسيطة.

طريقة النشر:
1) أنشئ حساباً في https://vercel.com
2) أنشئ مستودع GitHub جديداً وارفع إليه index.html و vercel.json.
3) من Vercel اختر Add New -> Project ثم اربط المستودع.
4) لا تحتاج إلى Build Command أو Output Directory؛ اختر Other إذا طُلب نوع المشروع، ثم Deploy.

مهم:
هذا نموذج واجهات وتجربة تفاعلية فقط. البيانات تجريبية ومحفوظة في ذاكرة الصفحة أثناء الجلسة، ولا توجد قاعدة بيانات أو تسجيل دخول SMS أو مزامنة فعلية بين الأجهزة أو حماية مالية إنتاجية بعد.
المرحلة التالية لربطه فعلياً: Supabase (PostgreSQL/Auth/RLS/Realtime/Storage) مع OTP ومراجعة صلاحيات الخادم قبل تسجيل أي رصيد حقيقي.
